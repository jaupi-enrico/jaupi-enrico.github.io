FLAGSHIP 2026 · SERVER + APP

Streamio

Your movies. Your shows. Your server.

A self-hosted, Netflix-style streaming platform for the media library you already own: a TypeScript server with a web UI, plus a Flutter app for phone, TV and desktop. One docker compose up and it's yours.

  • Adaptive HLS transcoding
  • Accounts, Google & Discord OAuth
  • Real-time watch parties
  • Custom Chromecast receiver
  • Multi-server sync
  • Encrypted offline downloads

Streamio Server

The backend and web frontend. Uploads are transcoded to adaptive HLS with resumable watch history; JWT sessions with Google & Discord OAuth and TV device-code pairing; WebSocket watch parties; a custom Cast receiver for demuxed HLS; cross-instance sync; PostgreSQL that migrates itself at boot; optional idle auto-shutdown of the host.

TypeScript Node.js Express PostgreSQL Redis WebSocket Docker
streamio-app REPO ↗

Streamio App

One Flutter codebase for phone, TV and desktop, covering everything the web UI does. Adds offline downloads that resume segment by segment, are stored AES-CTR encrypted with a key in the platform keystore, and play back through a local, range-aware HLS server.

Flutter Dart HLS Chromecast Drift AES-CTR
